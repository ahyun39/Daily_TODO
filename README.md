## 기능

- **캘린더** — 날짜 클릭으로 해당 날의 할 일 확인. 연도·월 클릭으로 빠른 이동
- **오늘 버튼** — 날짜 텍스트 옆 버튼으로 오늘 날짜 및 캘린더 현재 월로 즉시 이동 (오늘이 아닌 날짜 선택 시에만 표시)
- **메모** — 게시판형 메모 목록. "메모 추가" 버튼 클릭 시 textarea 폼 인라인 펼침. 저장 시 작성 날짜 자동 표시 및 캘린더 해당 날짜에 점(·) 표시. 최신순 정렬
- **할 일 추가·수정** — 입력 후 Enter 또는 추가 버튼으로 등록. ✎ 버튼으로 인라인 수정 (Enter 저장 / Escape 취소)
- **완료 체크** — 체크박스 클릭 시 취소선. 진행률 실시간 표시
- **루틴 관리** — 반복 주기(매일 / 매주 / 매월 / 매년)와 종료 조건을 설정해 해당 날짜에 자동으로 할 일 추가. ✎ 버튼으로 이름·설정 수정 가능
  - 매주: 요일 복수 선택 (일~토), 초기화 버튼 제공
  - 매월: 특정 일(1~31) 지정
  - 매년: 특정 월·일 지정
  - 시작 시점: 생성일부터 / 전체 기간(과거 날짜 소급) 선택
  - 종료 조건: 없음 / 횟수(주기 단위) / 특정 날짜
- **진행률 이미지** — 완료율에 따라 캘린더에 이미지 표시 (30% 이하 / 70% 이하 / 70% 초과). 미방문 날짜도 루틴 적용 여부에 따라 즉시 표시

## macOS 매일 오전 9시 자동 실행

1. todo.html을 원하는 위치에 저장 (예: /Users/[user_name]/[folder_name]/todo.html)

2. `com.user.todo.plist.template` 파일을 다운로드 한 후, `com.user.todo.plist`로 이름 변경

3. plist 안의 경로를 1번에서 저장한 실제 경로로 수정

```xml
<string>/Users/[user_name]/[folder_name]/todo.html</string>
```

4. plist를 macOS LaunchAgents에 등록

```bash
cp com.user.todo.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.user.todo.plist
```

등록 해제:

```bash
launchctl unload ~/Library/LaunchAgents/com.user.todo.plist
```

## 데이터 초기화(방법 2로 실행하는 경우)

1. 앱이 열린 브라우저 탭에서 아래 단축키로 개발자 도구를 엽니다
   - **Chrome / Firefox**: `F12` 또는 `Ctrl+Shift+J` (Windows) / `Cmd+Option+J` (Mac)
   - **Safari**: `Cmd+Option+C`
2. **Console** 탭을 클릭합니다
3. 아래 코드를 붙여넣고 Enter를 누릅니다

```js
['paper-todo:todos', 'paper-todo:routines', 'paper-todo:memos', 'paper-todo:memo-counter', 'paper-todo:migrated', 'todos', 'routines'].forEach(k => localStorage.removeItem(k));
location.reload();
```

4. 페이지가 새로고침되며 모든 데이터가 초기화됩니다

| 구분 | 기존 방식 | 개선 방식 |

| **기존 데이터 호환** | — | 기존 루틴 데이터 형식 그대로 유지 |
